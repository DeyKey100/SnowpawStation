# Управление

В проекте используется только новый Unity Input System
(`com.unity.inputsystem`). Старый API `UnityEngine.Input` не используется.
Игровые действия подключаются через Input Actions или API нового Input System.

| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Осмотр | Мышь |
| Взаимодействие | E |
| Колка дров | Space во время мини-игры |
| Подача топлива | Зажать ЛКМ |
| Открыть блокнот | Tab |
| Пауза | Esc |

Взаимодействие с объектом происходит, когда он находится в центре экрана, попадает в слой интерактивных объектов и находится не дальше трёх метров. Подсказка появляется над нижней частью экрана.

Управление рассчитано на клавиатуру и мышь. Поддержка контроллера пока не планируется.
