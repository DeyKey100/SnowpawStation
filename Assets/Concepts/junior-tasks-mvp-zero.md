# Задачи для первокурсников (дни 1–3)

Документ описывает пул несложных задач для трёх первокурсников в рамках
`mvp-zero-version-roadmap.md`. Объём — **только нулевая версия: 2–3 игровых дня**.



## 1. UI и обратная связь 

|#|Задача|Что делаем|Критерий приёмки|
|-|-|-|-|
|**A1**|Дебаг-HUD «День / Фаза»|Canvas Overlay + TextMeshPro, подписка на `DayLoopManager.PhaseChanged`, префикс `\[DEBUG]`, чекбокс «показывать»|В игре видно «День 1 · Утро»; после расчистки обязательного сугроба меняется на «WorkShift»; на дне 2 счётчик растёт|
|**A2**|Индикатор тепла + счётчик дров|Шкала `Image.type = Filled` на `StationHeatSystem.HeatChanged`, цвет зелёный → синий; рядом 3 иконки поленьев на `FirewoodStorage.FirewoodChanged`|Шкала падает со скоростью `heatLossPerSecond`, прыгает на +30 после полена; иконки гаснут/зажигаются; при 3/3 подсказка у колоды не появляется|
|**A3**|Прицел|Точка 4×4 px в центре|Виден приел|
|**A4**|Переход на Input Actions (`controls.md`)|Заменить `Keyboard.current.eKey` на экшен `Interact`; добавить кулдаун 0.25 с от двойного нажатия `E`|`E` работает через Input Actions; во время анимации сугроба повторное `E` ничего не запускает; смена раскладки не требует правки кода|
|**A5**|Пауза по `Esc`|`Time.timeScale = 0`, панель «Продолжить» / «Начать день заново» (`SceneManager.LoadScene`), освобождение курсора|В паузе тепло не падает и `PlayerInteraction` не срабатывает; после «Продолжить» всё как было|



## 2. Атмосфера: звук и снег 

|#|Задача|Что делаем|Критерий приёмки|
|-|-|-|-|
|**B2**|Шаги по снегу|`FootstepPlayer`: AudioSource + случайный клип + шаг по пройденному расстоянию, не по таймеру. Временные клипы уже лежат в `Assets/StarterAssets/.../Sfx/Player\_Footstep\\\_\\\*.wav`|Хруст совпадает с движением, стоя на месте - тишина, один и тот же клип не играет дважды подряд|
|**B3**|Звуки станции|Новая папка `Assets/Game/Audio/` + 4–6 клипов: ветер, треск печи, скребок лопаты. Компонент `AudioCues` с рандомом питча ±5 %|Ветер громче на дне 3; треск печи стихает при `CurrentHeat < 25`; скребок играет ровно один раз за расчистку|
|**B4**|Снежный «пуф» при уборке|One-shot ParticleSystem на сугробе; в `SnowPileInteractable` добавить только `\[SerializeField] ParticleSystem clearBurst;` и один `Play()` в начале `ClearSnowRoutine`|Эффект в самом начале оседания; работает и на обязательном, и на дополнительном сугробе; логика уборки не изменена (diff ≤ 5 строк)|
|**B5**|Холод при `CurrentHeat < 25`|`ColdEffects`: синяя виньетка через URP Volume (Vignette + Color Adjustments), −30 % к скорости игрока, шипение радио|Эффекты плавно нарастают и **полностью** исчезают после полена в печь; проигрыша и смерти нет|



## 3. Данные и мини-игры дней 1–3 

|#|Задача|Что делаем|Критерий приёмки|
|-|-|-|-|
|**C3**|Письмо Котова в UI|Панель-«открытка» с `DayConfig.letterText`, открывается по `E` вечером, закрывается по `Esc`/`Tab`|В дни 1–3 показываются три разных текста из `story.md`; после закрытия курсор снова захвачен игрой|
|**C4**|Мини-игра «Колка дров», упрощённая|Бегунок по шкале + зелёная зона, удар `Space`, успех → `FirewoodStorage.TryAddFirewood()`. Один новый скрипт + один Canvas|Попадание даёт +1 полено (макс. 3); промах ничего не ломает, можно бить снова; во время мини-игры `E` не срабатывает на других объектах|
|**C5**|Мини-игра «Топливо» — **выдавать последней, в паре с второкурсником**|`FuelPumpInteractable : IInteractable` на готовые `PF\_fuel\_pump`: зажать ЛКМ → литры растут, отпустить → стоп; сравнение с заказом: ±0.5 л идеально, ±2.0 л принято, иначе недовольство|Заказ 80 л выполняется; результат виден в UI; повторный клик не запускает вторую подачу; колонки уже стоят в сцене — новая геометрия не нужна|



## 4. Общие задачи на процесс (по одной на каждого, 2–3 ч)

* **Q1. Чек-лист готовности.** Перенести 10 пунктов из «Критерии готовности
нулевой версии» в шаблон GitHub Issue; прогнать дни 1–3 руками и завести
баг-репорты. Учит читать чужой код глазами тестировщика.
* **Q2. Тестовая сцена `InteractionSandbox`.** Пустая сцена: пол, куб-печь,
куб-сугроб, колода, игрок. Чтобы проверять механики за 5 секунд, не загружая
станцию. Учит собирать сцену и префабы.
